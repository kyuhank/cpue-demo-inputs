# Assessment input preparation

Checks and combines the CPUE index and extracted catches into assessment inputs.

Part of the [CPUE workflow demonstration](https://github.com/kyuhank/cpue-actions-demo). The central runner retrieves a locked commit, supplies shared model utilities and records inputs, outputs and provenance. All example data are synthetic.

[HTML job outputs](https://kyuhank.github.io/cpue-demo-inputs/). Results are selected by run ID and served from the recorded execution artifacts.
