# Assessment input preparation

Arrange the CPUE index and annual catch in the format required by the assessment.

- **Inputs:** A CPUE index and extracted catches.
- **Outputs:** Checked model inputs (`assessment-input.csv`) and their input record.

Part of the [CPUE workflow demo](https://github.com/kyuhank/cpue-actions-demo), using synthetic data and toy models. Each run records the exact code commit and input/output hashes.
